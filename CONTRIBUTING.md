# Contributing

Open an issue before making a large schema or command-contract change.

For a code change:

1. Use fictional data only.
2. Add a test that demonstrates the behavior.
3. Run the test, style, security, dependency, and fictional smoke checks.
4. Explain any compatibility or migration consequence in the pull request.

Do not submit real personal reports, identities, database files, backups,
credentials, absolute home paths, or agent session identifiers.
